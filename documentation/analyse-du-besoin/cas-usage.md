Cas d’usage :

Le but est de comprendre l’utilité des données une fois qu’elles seront collectées, transformés et mises à disposition. Aussi cette étape nous permet de savoir qui va exploiter les données et si elles répond bien à leur besoin .

-Différents cas d’usage :

Suivi de la qualité de l’air
Les chercheurs peuvent consulter les indicateurs de qualité de l’air dans différentes villes pour suivre l’évolution dans le temps. 

Analyse des données météo
Les données météo sont utilisées pour compléter les analyses et comprendre leur impact sur la qualité de l’air. 

Création de Dashboard
Les utilisateurs peuvent accéder à des visualisations (graphiques, tableaux) pour mieux lire et interpréter les données. 

Détection d’anomalies
Le système permet d’identifier des situations inhabituelles (pic de pollution) afin d’alerter les équipes. 

Études et recherches avancées
Les données peuvent être exportées pour être utilisées dans des analyses plus poussées .
